# Chess Game With AI
This is a Chess game in python using AI algorithms
# Project Description:
Chess is a strategic board game that people play and enjoy competing each other. With advancements in artificial intelligence, This project aims to develop a player vs computer and a player vs player chess game using AI techniques in Python. 
# AI algorithms:
We use MiniMax algorithm and optimized with alpha-beta pruning to enhamce the performance
# How to play:
'r' -> to reset the game
't'-> to change the theme between Green,Brown,Blue, and Gray
'a' -> to change the gamemode between AI vs human, and human vs human
3 or 4 -> to change AI depth
